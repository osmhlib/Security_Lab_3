# ЛР №3. Валідація вхідних даних

Один проєкт із двома способами запуску:

- **Локально (Flask):** JavaScript перевіряє поля, після чого Flask повторно перевіряє дані на сервері.
- **GitHub Pages:** відкривається кореневий `index.html`, працює лише JavaScript, без надсилання даних на сервер.

## Локальний запуск

```powershell
py -m pip install -r requirements.txt
python app.py
```

Відкрийте http://127.0.0.1:5000. Для локального режиму використовується `templates/index.html`.

## Публікація GitHub Pages

1. Завантажте **весь вміст** цієї папки в один GitHub-репозиторій, так щоб `index.html` був у корені.
2. Відкрийте **Settings → Pages**.
3. У **Build and deployment** встановіть **Deploy from a branch**, виберіть `main` і папку **/(root)**; натисніть **Save**.
4. Після публікації відкрийте адресу, яку покаже GitHub Pages.

Статичний сайт читає `index.html` і `static/`; він не запускає `app.py`.

## Перевірки

- Логін: 5–30 символів.
- Ім’я: тільки літери.
- Пароль: 8+ символів, щонайменше одна велика літера і цифра.
- Email: `@` і домен з крапкою.
- Телефон: 9–15 цифр, необов'язковий `+` на початку.
- Дата народження: реальна дата, не пізніше сьогодні.

`reports/` призначена для звітів і результатів тестування.

**Увага:** це навчальна форма, реєстрації та збереження даних немає. На публічному GitHub Pages не вводьте реальні паролі. Flask `debug=True` лише для локальної розробки.
